# Source Universal Tracker bridge

Roster gates every generated check and completion condition behind that game's Unlock. Ordinary Universal Tracker regenerates a single-game world and cannot reproduce this cross-slot rule itself.

`RosterTracker.py` adds the live Roster gate to a source-runtime UT process. Locked games report zero reachable checks; unlocked games use their existing game rules and received items. Installed AP and UT files are unchanged.

Use an Archipelago source checkout with its Python dependencies, the game's apworld, and Universal Tracker installed. Frozen installer executables are unsupported. Tested with AP 0.6.7 and official UT v0.3.3. Keep the Roster client running with its `--state-file` option, then launch:

```powershell
python RosterStandalone.py --name Roster --connect server:port --state-file C:/path/to/roster-state.json
```

In another terminal (using the same state path):

```powershell
python RosterTracker.py --archipelago C:/path/to/Archipelago --roster-state C:/path/to/roster-state.json --slot "Game 01" --connect server:port
```

Give UT only the corresponding `game_01.yaml` when YAML is required. The neutral slot must match exactly. The JSON snapshot must name the same seed as UT, be connected, list that slot as unlocked, and be no older than 30 seconds. Missing, malformed, disconnected, expired or wrong-seed state closes the gate. UT refreshes every second; the Roster client refreshes its snapshot every five seconds.

This is local presentation and logic integration, not access control. YAML contents, game identity, checked-location history and other metadata can remain visible. Region and entrance displays are not hidden.

Validation from the Roster checkout:

```powershell
python -m unittest test_roster_tracker.py
python test_roster_world.py --archipelago C:/Users/alari/Archipelago
```

For the runtime smoke test, extract the official [UT v0.3.3 release](https://github.com/FarisTheAncient/Archipelago/releases/tag/Tracker_v0.3.3) `tracker.apworld` as a ZIP into a temporary directory, without installing it. Pass its extracted `tracker` directory:

```powershell
python test_roster_tracker_runtime.py --archipelago C:/Users/alari/Archipelago --tracker-source "$env:TEMP/roster-ut-validation/tracker"
```

The runtime test calls the actual UT context and calculation core with an APQuest world generated by AP. It verifies locked zero checks, unlocked checks, wrong-seed/missing-state relocking, and idle refresh. It does not validate a connected GUI session or every custom world's UT support. Existing rooms are untouched.
